@@AGGREGATION_EXPLANATION@@

Percentile colours distribute the ramp by visible-sample rank, with tied stored scores sharing a colour. Min–max colours linearly stretch the lowest and highest visible scores. Both use all target samples passing the current raw threshold, independent of zoom. Axis and threshold changes can change the mapping; use Fixed 0–1 to compare raw strength by colour across selections. Filtering, popup intensities and candidate rankings always use the original scores.

Scores for all 255 nonempty axis selections were computed on RunPod. PCA axes represent variation, not clusters.

Colour shows per-sample intensity, not sample density. Footprints are display markers, not interpolated area boundaries. Unsampled locations carry no inference. Stored intensity resolution is 1/256.
